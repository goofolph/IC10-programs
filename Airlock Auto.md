# Airlock Auto

Automatic Airlock. Uses a player sensor and and batch read/writes to control the airlock. This is using batch read/write so the power/data network should be isolated behind a area power controller.

Uses internal and external pressure sensors to match pressure between the two for automatic door cycling.

## Setup

- Airlock Gas Sensor (if using a large hangar style airlock put one sensor at the farthest grid from the vent or one in each grid)
- Airlock Gas Sensor External
- Airlock Gas Sensor Internal
- Airlock Door Internal
- Airlock Door External
- Airlock Vent Internal
- Airlock Vent External
- Occupancy Sensor
